# Campaign Analysis

Turn metrics into a decision, not a dashboard recap.

## Workflow

1. Normalize the reporting period, platforms, organic/paid scope, and metric definitions.
2. Compare performance to a stated baseline or label it as descriptive only.
3. Separate reach, attention, engagement quality, conversion, and audience feedback.
4. Identify one or two plausible hypotheses and the smallest next experiment.

## Output

Return a short report with:

- what happened;
- evidence and data gaps;
- what to continue, stop, or test next;
- the primary metric and review window for the next iteration.

## Boundaries

- Do not compare incompatible platform metrics as if they were identical.
- Do not claim causation without an experiment or appropriate baseline.
- Request only the minimum API data needed; do not expose raw tokens or private account data to the analysis model.
